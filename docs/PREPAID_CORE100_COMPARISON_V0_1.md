# Prepared prepaid Core100 comparator V0.1

This is a disabled, comparison-only successor composition. It reuses the frozen Core100 V0.2 contract, implementation/authority validation, dataset index, fingerprint collector and comparator without editing their files or changing the experiment identity. It reserves a fixed envelope of at most 32 R2 LIST and 32 GET attempts, zero provider calls and zero R2 write bytes through V0.5 shared admission. The D1 ticket separately pre-funds its own admission and replay reads. A bounded whole-bucket size scan precedes reads; at 32 pages, incomplete pagination, inconsistent metadata, unknown evidence or exhausted limits it stops for review.

The read-only facade accepts only the governed latest pointers, Core100 catalog and shard receipt JSON, and the bound fingerprint manifest. It blocks model, metrics, raw historical partitions and holdout-content reads; each object and aggregate response is byte-bounded. The bucket-size scan lists object metadata across the bucket, as the existing headroom check does; it does not fetch object contents. No write method is exposed to the frozen comparison code.

A valid compare can only return `NO_CHANGE` or `REVIEW_REQUIRED`; it never trains, bootstraps or promotes. Tests use an in-memory S3 client and SQLite, with fixture substitution for the comparator chain. The existing frozen fingerprint suite remains the evidence for fingerprint semantics. These checks do not verify live D1, writer coverage, account headroom, current job identity, or production execution provenance.

The `verify_source` callback is a preparation seam, not an authenticated source or permission boundary. It must be a bounded, pre-authorized source check without hidden external I/O; a future independent gateway must establish the real source, caller, exclusive namespace ownership and cost scope. The original scheduled workflow still uses its direct legacy path; this module adds no workflow, cutover, schedule, execution authority, token, R2/D1 access or provider request. Historical bootstrap and diagnostic authorities remain consumed.
