# Validated complete-tape inputs V0.1

The disabled prepaid Cloud Paper runtime validates raw depth and trades from the existing bounded Cloud Paper transport before the legacy parser can discard malformed depth rows or coerce boolean price/size values. It also checks every parsed lifecycle trade and book price/size for finite positive values before aggregation. Conflicting prices with the same trade timestamp fail closed because their true intra-millisecond order is unproven; this conservative rule may stop a liquid market even when the ambiguous records precede the relevant interval.

Valid data still makes the same two provider requests; other client methods delegate unchanged. CI exercises raw JSON structures and synthetic feed behavior. This does not prove live provider format, tape completeness, strategy qualification or production activation. The existing saturation, gap, freshness, budget and frozen source boundaries remain in force. Full open-position composition failure/retained-reservation coverage remains a separate test requirement.
